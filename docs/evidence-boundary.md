# Evidence boundary

The portfolio distinguishes three things:

1. **Experience context** — professional information reported by a public
   profile and still subject to human disclosure review.
2. **Public reproduction** — a new project that demonstrates an implementation
   capability without claiming to be employer or client code.
3. **Public evidence** — a repository or artifact that a visitor can open and
   inspect.

A public reproduction does not prove that the same implementation was used in a
previous job. It proves that the capability has been implemented publicly.

The portfolio must not add private paths, credentials, client data, employer
details, invented metrics, or production claims unsupported by an evidence link.

## Commercial paths

The public site keeps employment/recruiting opportunities separate from
exploratory services or systems-review discussions. The professional path points
to the existing public profile. The systems-review path points visitors to
published examples and is explicitly exploratory, not a validated or packaged
service; it does not imply client delivery. Do not add contact details, forms, or
outreach automation without separate review and approval. Revisit the services
wording only when new public evidence supports a more specific claim.
