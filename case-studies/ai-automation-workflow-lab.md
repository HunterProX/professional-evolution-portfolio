# AI Automation Workflow Lab — public reproduction

## Classification

This is a new public reproduction of a bounded workflow. It is not a client
workflow, Personal OS integration, autonomous production system, n8n workflow,
or OpenClaw deployment.

## What was implemented

- Synthetic input contract.
- Explicit proposal, approval, rejection, and execution states.
- Allowlisted deterministic actions.
- Idempotency key and replay-safe execution.
- Audit event for every state transition.
- Invalid-input and approval-bypass tests.

## What this demonstrates

- Human-in-the-loop workflow design.
- State transitions and approval boundaries.
- Deterministic actions and auditability.
- Safe duplicate execution behavior.

## What this does not demonstrate

- Autonomous production automation.
- External service integration.
- Private system writes.
- Client data or employer workflow implementation.
- n8n, OpenClaw, or agent runtime operation.
